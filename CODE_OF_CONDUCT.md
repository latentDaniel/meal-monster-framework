# Code of Conduct

## Our standard

This project welcomes contributions, questions, and feedback from anyone. We expect everyone interacting in this repository's issues, pull requests, and discussions to:

- Be respectful and assume good faith.
- Focus on the technical merits of ideas, not on people.
- Disagree without being dismissive.
- Keep discussion on-topic and constructive.

## Out of scope

This is a personal-project framework, not a community platform. Discussions should stay focused on the framework itself: prompts, templates, agent design, documentation, and the technical questions around using it. We do not host general nutrition debates, medical advice, dietary ideology arguments, or political conversations in this repository.

For anything outside that scope, please take the discussion elsewhere.

## Enforcement

The maintainer reserves the right to lock threads, close issues, hide comments, or block users whose behavior is unproductive — at the maintainer's discretion. If you believe enforcement was applied unfairly, open a calm issue explaining why.

## Reporting

If something in an issue or PR makes you uncomfortable, mention it in-thread or contact the maintainer via the email address on the maintainer's GitHub profile.
